# Le Classico

Maquette du site de réservation de terrains de foot à 5 à Brazzaville.

Site statique : `index.html`, `hero.mp4` et `hero-poster.jpg`, sans installation.

## Publier avec GitHub Pages
Settings → Pages → Source : Deploy from a branch → `main` / `(root)`.

## À remplacer avant la mise en ligne
- Numéro WhatsApp : constante `WA` dans le script de `index.html` (format `242XXXXXXXXX`) et numéro affiché dans « Infos pratiques ».
- Adresse, tarifs (fonction `price`) et horaires.
- Créneaux occupés : simulés pour la démonstration.
